# أثَر ATHAR — متجر أزياء وعطور

موقع متجر ثابت (HTML/CSS/JS بدون أي مكتبات) بالعربية RTL.

- `index.html` — المتجر
- `brand.html` — هوية العلامة (اللوجو، الألوان، الخطوط)
- `assets/js/main.js` — المنتجات والسلة. عدّل `CONFIG.whatsapp` لرقمك، والمنتجات في مصفوفة `PRODUCTS`.
- الطلبات تُرسل كرسالة جاهزة عبر واتساب.

صور المنتجات للعرض من Unsplash.
